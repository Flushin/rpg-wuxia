# Música (arquivos em `public/audio/music/`)

Coloque em `public/audio/music/` as faixas (loop) em dois formatos cada, com estes nomes:

- cidade.ogg / cidade.mp3 (mapa "cidade", chave music_cidade)
- floresta.ogg / floresta.mp3 (mapa "floresta", chave music_floresta)

Os arquivos são opcionais: se faltarem, o jogo roda sem música. Mapeamento e volume base em src/data/audio.json.
